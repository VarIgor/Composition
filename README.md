### Composition
___
This application was created as part of a training course. The goal is to develop skills and try out new technologies, in particular: the project structure adheres to 
the principles of clean architecture. The application is built on fragments and has one activity. 
Navigation between fragments is implemented using the jetpack navigation library.
This application will be useful for primary school students, allowing them to quickly learn to count.
___
### Rules of the game
There will be three figures in front of you, two below and one above, two of them will have numbers. It is necessary that the sum of the numbers from the two lower figures is equal to the number in the upper figure; to do this, you need to insert the missing number. Example: in the upper circle there is the number 7, in one of the lower circles there is a question mark, and in the other there is the number 4. This means that in place of the question mark there should be the number 3, because 3 + 4 = 7.
